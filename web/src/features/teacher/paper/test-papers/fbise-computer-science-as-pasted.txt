Section A: Multiple choice (25 marks)
Choose the best answer. Each question has 1 mark.
1. A signal that has only two fixed levels, such as 0 and 1, is called a/an: [1 mark]
a) analog signal  b) continuous signal  c) digital signal  d) sine wave
Answer: c
2. Which of these is an example of an analog quantity? [1 mark]
a) Room temperature changing through the day  b) Number of students in a class  c) The binary number 1011  d) Number of pages in a book
Answer: a
3. Which logic gate gives output 1 only when all of its inputs are 1? [1 mark]
a) OR  b) NOR  c) XOR  d) AND
Answer: d
4. The output of a NOT gate is 0 when its input is: [1 mark]
a) 0  b) 1  c) either 0 or 1  d) no input
Answer: b
5. A truth table for a Boolean expression with 4 input variables has how many rows? [1 mark]
a) 4  b) 8  c) 12  d) 16
Answer: d
6. Which gate gives output 1 when its two inputs are different? [1 mark]
a) XNOR  b) AND  c) XOR  d) NAND
Answer: c
7. NAND and NOR are called universal gates because: [1 mark]
a) they are the cheapest gates  b) any other gate can be built using only NAND gates or only NOR gates  c) they can have only one input  d) their output is always 1
Answer: b
8. If A = 1 and B = 0, the output of a NOR gate, (A + B)', is: [1 mark]
a) 0  b) 1  c) 10  d) undefined

a) A + 1 = 1  b) A·0 = 0  c) A' + 0 = A'  d) A·1 = A

26. Differentiate between analog and digital signals. Give one example of each. [3 marks]
Answer: An analog signal is continuous and can take any value within a range, for example a sound wave from a microphone or the temperature changing through the day. A digital signal is discrete and has only two levels, 0 and 1, for example the data a computer stores and processes. (1 mark for each definition, 1 mark for correct examples.)

28. State the principle of duality. Then write the dual of each expression. [3 marks]
a) A + A' = 1
b) A·(B + C) = A·B + A·C
Answer: If a Boolean statement is true, it stays true when every AND (·) is changed to OR (+), every OR to AND, every 0 to 1 and every 1 to 0. The variables do not change. [1]
a) A·A' = 0 [1]
b) A + B·C = (A + B)·(A + C) [1]
29. A school wants to connect 6 computers in its computer lab. Answer both parts.
a) How many cables are needed in a full mesh topology? Show your working. [2]
b) Give one reason the school might choose star topology instead. [1]
Answer: a) Cables = n(n − 1) ÷ 2 = 6 × 5 ÷ 2 = 15 cables. b) Star needs only 6 cables, one from each computer to the switch, so it is cheaper and new computers are easy to add. A broken cable stops only one computer.
30. Answer both parts.
a) Write two differences between symmetric and asymmetric encryption. [2]
b) Give one way a user can protect themselves from phishing. [1]
Answer: a) Symmetric encryption uses one shared secret key to both encrypt and decrypt; asymmetric encryption uses a pair of keys, a public key to encrypt and a private key to decrypt. Symmetric is faster and suits large amounts of data; asymmetric is slower but removes the need to share a secret key safely. b) Any one: check the sender's address and the website link before clicking; never type a password on a page opened from an email link; turn on two-factor authentication.

32. Answer all parts about the Software Development Life Cycle (SDLC).
a) List the main phases of the SDLC in the correct order. [2]
b) Write two differences between the Waterfall model and the Agile model. [2]
c) A startup is building an app, and its users will ask for new changes every few weeks. Which model should it use? Give one reason. [1]
Answer: a) Planning and requirement analysis → design → coding (implementation) → testing → deployment → maintenance. Accept the book's phase names if they match in meaning.
b) Waterfall finishes each phase fully before the next one starts; Agile works in short, repeated cycles called sprints. In Waterfall, changes are hard and costly once a phase is done; in Agile, changes are expected and added in the next sprint. Also accept: Waterfall tests near the end while Agile tests in every sprint; Waterfall involves the customer mainly at the start while Agile involves them after every sprint.
c) Agile, because it delivers the app in small parts and takes in user feedback after every sprint.
